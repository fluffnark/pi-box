# Agent task acceptance checklist

- [ ] Recognizes no printer / no printed mounting requirement.
- [ ] Visually reviews original measured lid and ribbon photos.
- [ ] Distinguishes panel glass from active area and marks pending caliper measurements.
- [ ] Defines a feasible panel retention path without adhesive on fragile glass.
- [ ] Defines a compatible PP bond solution (e.g. VHB LSE), available tape land, surface prep, load and serviceability limitations.
- [ ] Designs a noncontact protective window with adequate edge support and cut method; verifies optical/condensation concerns.
- [ ] Verifies the actual lid underside ribs, gasket, latch/hinge before specifying any hole/cut.
- [ ] Keeps FPC away from gasket and sharp bends; routes and relieves cable in both open/closed states.
- [ ] Verifies #4524/#4230 same-side cable requirements, pin numbering and continuity before powering.
- [ ] Separates already-owned vs ordered vs new vs unclear inventory items; gives real links for purchases.
- [ ] Generates 1:1 paper/cardboard template and shop-cut 2D file only after fit confirmation.
- [ ] Provides a low-cost work sequence and an inspection/leak-test plan; does NOT promise retained IP65 rating without proof.
